# 模因乱斗：抽象食物链

Godot 4.3+ 独立 2D 格斗原型，当前验证版本为 Godot 4.6.3。打开本目录 `project.godot`，按 F5；或运行 `sh run.sh`。首次打开先导入字体资源。

新增六角色技能特效、突进残影、分层打击音效、命中顿帧与必杀动作曲线。练习模式支持 1–3 必杀、Shift+数字 EX、4 CA。[效果与验证说明](docs/COMBAT_EFFECTS.md)。

## 街机界面与演出

新版采用对称生命条、延迟扣血、低血警示、独立 V 槽、三格超必杀槽、头像和真实回合胜点。普通与街机模式为先胜两回合，下一回合恢复生命并保留能量。加入 VS、FIGHT、CA 特写、KO 和回合／整场胜者面板。

按 **F3** 或点击“演出鉴赏”观看 72 秒六角色编排演示；Enter／空格跳过当前过场，Esc 退出。它是演出模式，不是完整竞技对局录像。[界面说明与截图](docs/UI_GUIDE.md) · [MP4 实机演示（单独下载）](https://github.com/2502511622-rgb/rouge/raw/refs/heads/main/Meme-Brawl-Showcase.mp4)。

## 键位

| 操作 | 按键 |
| --- | --- |
| 移动/跳/蹲 | A D / W / S |
| 站防/蹲防 | 远离对手 / 远离对手 + S |
| 轻中重拳 | J K L |
| 轻中重腿 | U I O |
| 投技 / V 技能 / V 触发 / 挑衅 | G / V / B / T |
| EX | 搓招 + Shift + 对应攻击，或搓招后快速双击重攻击 |
| CA | ↓↘→↓↘→ + 拳（满 3 格） |
| 手册 / 暂停 / 静音 | F1 / Esc / M |
| 演出鉴赏 / 跳过过场 | F3 / Enter 或空格 |
| 练习重置 | R |

右朝向的波动指令：S → S+D → D → J。左朝向镜像输入。升龙：D → S → S+D → 攻击。所有必杀指令在 F1 手册中。快速双重攻击的 EX 是输入宽容实现；推荐 Shift，避免首击先触发普通必杀。

## 企鹅与妙脆角猫完善版

默认对局为咕咕嘎嘎对妙脆角猫。两人各新增一张 **4×4、16 个独立关键姿势**的透明动作图集（`gugu_actions.png`、`cat_actions.png`），27 个状态片段改用这些姿势；其余四角色继续使用总图集。企鹅暂沿用最初指定的动物版；公开存在的管理员连帽二创版已记录为另一版本，不混称首发原型。

**咕咕嘎嘎**：双脚交替走路、起跳/落下、鳍击、低踢/高踢、张嘴音波、腹部滑冲、空中旋踢、防御、受击与倒地各有关键姿势。迁徙 V 仍提供 3.5 秒加速与二段跳，并让滑冲/旋踢获得强化判定而不扣 EX 能量。普通滑冲穿过短暂窗口内的高位飞行道具，低位攻击仍能打中；EX 空中俯冲会向下加速并击倒；旋踢为两段（强化三段），期间可用 A/D 空中调整。EX 音波改为按 0.12 秒间隔依次出现的三道弹，不再同时重叠。胜利跳跃转圈，CA 有多层音波环。

**妙脆角猫**：形象改为大眼、灰白、短腿圆猫，16 姿势涵盖步行、跳跃、爪击、投射、当身、无角、格挡和躺倒。金色脆角作为独立部件绘制；发射后 2.6 秒、成功反击后 3 秒消失，再生后自动恢复，HUD 显示倒计时。无角期间的波动变为较弱、外形较钝的气团（32 伤害，原角弹 65）；无角反掌较弱但获得更多能量。普通爪击有 0.09/0.125/0.16 秒前摇。

猫的歪头拍击是可被打断前摇的当身（普通 0.18 秒、EX 0.08 秒），V 当身仍可立即响应；慵懒滑步是后撤站防，不再误触发反击。EX 脆角即使未命中也会下落并留下持续 2.6 秒的碎片，踩到造成低段伤害和 0.42 秒绊停，消耗该陷阱；跳跃可以避开。无角 EX 留下的碎片伤害较低。胜利时原地趴下，CA 有环绕脆角演出。

专项测试覆盖迁徙强化不扣能量、高/低位飞行道具区别、空中俯冲/旋踢、分批音波、角消失与再生、钝角弹变化、后撤格挡与当身区别、当身前摇可打断、未命中 EX 落地陷阱、跳跃避开和踩踏消耗。动作播放测试现在检查实际独立图集、姿势编号和播放推进。

## 黄色三幻神 · 已加入可选阵容

三个新角色直接可选，不设付费解锁。按 1–6 快速选角，鼠标可切换对手；F1 显示当前选中角色的准确指令。原三角克制只作用于最初三角色，新增角色不获得隐藏克制加成。

| 角色 | 普通必杀（面向右） | EX | CA |
| --- | --- | --- | --- |
| 奶蛙 | ↓↘→+拳 黏液；→↓↘+拳 突进；↓↙←+脚 蛙跳震地 | 波动拳改为多段翻滚；升龙拳改为三段扑击 | ↓↘→↓↘→+拳 胞兄厌我 |
| 牛来 | ↓↘→+拳 冲撞；→↓↘+拳 上挑；↓↙←+拳 踩地 | 冲撞霸体；三段牛踏 | ↓↙←↓↙←+拳 妈妈救我 |
| 美团袋鼠 | ↓↘→+脚 重踢；→↓↘+拳 上挑；↓↙←+拳 外卖箱 | 三段跳踢；头槌霸体 | ↓↘→↓↘→+脚 胆子肥嘟嘟 |

- **V 槽**：新角色开局 100，最大 100，每秒恢复 3；有效命中增加 8，受击增加 12。与三格 EX/CA 能量独立。
- **奶蛙 V**：有效命中后的 0.3 秒内按 V，消耗 35 V 槽清除当前攻击与硬直；空挥/被防不能取消。B 触发 8 秒红屏状态，移动速度 ×1.45、攻击恢复时间 ×0.65，但受伤 ×1.25。突进低身位期间避开飞行道具。
- **牛来 V**：按 V 开始/暂停移动蓄力，最多 2.5 秒；下一个必杀按蓄力获得最高 ×1.875 伤害，随后清空。蓄力中受伤 ×1.25 且清空蓄力。EX 冲撞霸体仍扣血但不中断攻击，投技可破。B 持续 8 秒，打击范围扩展 110，呈现冲击波判定。
- **袋鼠 V**：举架 1 秒，格挡后自动反击，7 秒冷却，投技可破。B 持续 8 秒，打击伤害 ×1.2，跳跃初速提升，踢技变中段（站防有效，蹲防无效）。外卖箱首次命中或落地后弹跳，仍可再命中一次。
- **B 触发**：需满 100 V 槽，消耗全部 V 槽，不能在已有触发中重复发动。AI 同样使用这些机制。

奶蛙、牛来、袋鼠的配对台词已接入。街机依次挑战另外五名角色，通关有结局提示。CA 为标题特写与多段判定；牛来有母爱虚影轮廓，尚非完整剧情动画。当前原创合成音效不等于原版录音。

## 音频替换

当前已导入原创像素角色图集；**原版迷因录音尚未下载、导入**，运行时仍使用原创合成提示音。用户提供的三条抖音来源见 `assets/audio/sources.json`，请求均遭网络策略 403 拒绝。界面“已导入录音 0/6”反映实际素材状态。将你有权使用的 Ogg 文件放入 `assets/audio/`，Godot 导入后自动优先播放。文件名为 `{角色}_{动作}.ogg`：

- 角色：`gugu`、`dog`、`cat`、`naiwa`、`niulai`、`kangaroo`
- 动作：`intro`、`taunt`、`win`、`v`、`special`、`ca`、`swing`、`hit`、`block`、`trigger`
- 例如 `gugu_ca.ogg`、`dog_taunt.ogg`、`cat_ca.ogg`。

中文字体 Noto Sans CJK 随附，其许可证见 `assets/fonts/LICENSE.txt`。

## 像素美术与动画

`assets/art/meme_fighters_atlas.png` 是 6 列 × 4 行透明图集。列依次为六角色，行依次为待机、拳击、踢击、必杀表情。素材已依据实际查看的公开网络二创图片校正：奶蛙绿眼梨形大肚、牛来直立黄毛紫口鼻、肥嘟嘟长耳棕鼻，刀盾狗改为低趴圆滚滚柴犬。它们仍为原创像素重绘，不是原版视频抠帧。完整核对记录与链接见 [网络原型核对](docs/REFERENCE_RESEARCH.md)，来源清单见同目录 `sources.json`。

企鹅和猫使用各自的 16 姿势独立图集；其余角色使用上述总图集。`pixel_animator.gd` 为每个角色提供 27 个状态片段：待机、行走、蹲下、跳跃、轻/中/重拳、轻/中/重腿、三个必杀、三个 EX、CA、V 技能、V 触发、投技、受击、格挡、倒地、胜利、挑衅、蓄力与开场。动画与战斗状态相连，暂停时停止；CA 有角色特写，结算时播放胜负动作。

企鹅与猫使用各 16 张关键姿势，其余角色使用四张关键姿势，并结合变换关键帧；并非 27 套逐帧重画的独立精灵表。每个角色均验证了 27 个片段的实际播放推进，另做了真实 OpenGL 画面检查。

### 导入真实录音

提供原视频/音频文件后，可使用已测试的导入工具裁切、转为单声道 Ogg、处理响度并保存发布链接、作者、时间范围和 SHA-256。工具不抓取登录页面，不会把合成测试音写入游戏资源。已有录音默认禁止覆盖，需要显式 `--replace`。

```sh
python3 tools/import_voice.py /path/to/original-video.mp4 \
  --character naiwa --event ca --start 12.0 --duration 4.5 \
  --source-url https://v.douyin.com/r0TVToGOFAk/ --credit 奶皮蛙
sh run.sh --headless --editor --import --quit
```

上面起止时间只是命令格式示例，**尚未查看原视频，不能当作真实台词时间点**。需以实际录音为准。同样可导入 `intro`、`taunt`、`win`、`v`、`special`、`trigger` 等事件。导入后菜单显示有已登记可加载录音的角色数量；未提供录音的事件继续使用合成提示音。

用户指定来源：

- 奶蛙：奶皮蛙《奶蛙咒》 https://v.douyin.com/r0TVToGOFAk/
- 牛来：小楠漫剧《牛来找妈妈》 https://v.douyin.com/aeBNCaqxsxg/
- 袋鼠：想吃kfc“枪射不穿我屁股，记住我叫肥嘟嘟” https://v.douyin.com/pM6d5W2n1o4/ （来源标签为“美团老鼠”，游戏沿用用户指定角色名。）

网络访问变更已保存为环境草稿，待保存/发布使其生效；后续实际视频 CDN 域名需在解析出后按需放行。也可直接提供本地原始素材。

## 当前边界

这是可继续开发的格斗原型，不是完成商业美术与平衡的街霸级成品。美术为原创 AI 生成像素图集，含六角色总图集及企鹅/猫各 16 姿势独立图集，并有透明通道；不是从网络视频扒取的原版美术，没有真实 3D 转像素渲染管线。27 种状态动画由图集姿势切换、位置、旋转和压缩关键帧组成，覆盖六角色，但不等于每一帧都独立绘制的完整手绘动画。CA 加入角色像素特写与多段状态动画，仍不是完整剧情分镜演出。猫的陷阱和棱角变化、EX 以及攻击帧数是原型简化规则。尚无双人本地/联机、手柄、存档、音量滑杆和独立 BOSS 阶段；菜单已提供静音开关。Windows EXE 导出需 Godot 对应版本的导出模板，此目录交付可直接运行的 Godot 源工程。

完整原版梗音频、精确打击动画与最终平衡尚需后续制作；未声称已完成它们。
