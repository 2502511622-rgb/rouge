# 模因乱斗：抽象食物链

Godot 4.3+ 独立 2D 格斗原型，当前验证版本为 Godot 4.6.3。打开本目录 `project.godot`，按 F5；或运行 `sh run.sh`。首次打开先导入字体资源。

## 已实现

- 咕咕嘎嘎、刀盾狗、妙脆角猫；6 种普通攻击、站防/蹲防、跳跃、投技、击退、击倒、能量积累。
- 相对朝向的 0.85 秒搓招缓冲、必杀、1 格 EX、3 格 CA、V 技能和 7 秒冷却。
- 咕咕嘎嘎迁徙加速/二段跳/突进强化；狗盾反；猫当身、受击额外能量、角消失后的减伤变化。
- AI 对战、两战街机巡回、静止木桩练习、四个程序舞台、配对开场、胜负台词与九种配对结局。
- 血量、三格能量、99 秒计时、招式提示、招式手册、暂停、选角与重赛。
- 克制循环伤害 +8%：企鹅 → 狗 → 猫 → 企鹅。

## 键位

| 操作 | 按键 |
| --- | --- |
| 移动/跳/蹲 | A D / W / S |
| 站防/蹲防 | 远离对手 / 远离对手 + S |
| 轻中重拳 | J K L |
| 轻中重腿 | U I O |
| 投技 / V 技能 / 挑衅 | G / V / T |
| EX | 搓招 + Shift + 对应攻击，或搓招后快速双击重攻击 |
| CA | ↓↘→↓↘→ + 拳（满 3 格） |
| 手册 / 暂停 / 静音 | F1 / Esc / M |
| 练习重置 | R |

右朝向的波动指令：S → S+D → D → J。左朝向镜像输入。升龙：D → S → S+D → 攻击。所有必杀指令在 F1 手册中。快速双重攻击的 EX 是输入宽容实现；推荐 Shift，避免首击先触发普通必杀。

## 音频替换

当前仅附带运行时原创合成提示音，**没有原版迷因录音**。将你有权使用的 Ogg 文件放入 `assets/audio/`，Godot 导入后自动优先播放。文件名为 `{角色}_{动作}.ogg`：

- 角色：`gugu`、`dog`、`cat`
- 动作：`intro`、`taunt`、`win`、`v`、`special`、`ca`、`swing`、`hit`、`block`
- 例如 `gugu_ca.ogg`、`dog_taunt.ogg`、`cat_ca.ogg`。

中文字体 Noto Sans CJK 随附，其许可证见 `assets/fonts/LICENSE.txt`。

## 验证

```sh
sh run.sh --headless --editor --import
sh run.sh --headless -- --smoke-test
```

功能测试运行三角色真实攻击/EX/CA/V 逻辑，以及搓招匹配、格挡减伤、投技破防、企鹅二段跳、KO 结算和选角菜单。测试失败会触发断言；自动化建议外层设置 60 秒超时，同时检查输出含 `MEME BRAWL SMOKE PASS` 且无 `SCRIPT ERROR`。

## 当前边界

这是可继续开发的格斗原型，不是完成商业美术与平衡的街霸级成品。美术为程序绘制的粗粝多边形/像素风，没有真实 3D 模型转像素渲染管线。CA 使用特写标题、强化命中和击退，尚未制作完整多段演出；普通攻击暂无逐帧角色骨骼动画。猫的陷阱和棱角变化、EX 以及攻击帧数是原型简化规则。尚无双人本地/联机、手柄、存档、音量菜单和奶蛙 BOSS。Windows EXE 导出需 Godot 对应版本的导出模板，此目录交付可直接运行的 Godot 源工程。

完整原版梗音频、精确打击动画与最终平衡尚需后续制作；未声称已完成它们。
