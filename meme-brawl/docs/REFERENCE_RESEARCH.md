- https://github.com/chunchiehhou/naiwa-feidudu-niulai ：查看 `src/assets/pet/naiwa/naiwa-idle.png`，奶蛙绿眼、梨形、浅色圆肚与灰色手脚；README 列出三角色及动作。项目为 MIT，但本工程只作形象研究，没有复制该项目代码或素材。
- https://github.com/KevinKaslana093/yellow-anomaly ：查看 `public/assets/trio.png`、`ART-PROMPT.txt` 与 README。三者分别是绿眼梨形奶蛙、长耳棕鼻肥嘟嘟袋鼠、直立黄毛短角紫口鼻牛来。该图明确为 AI 重绘，不能冒充原始梗图。其 README 指向 3DM 介绍 https://www.3dmgame.com/original/3746364.html ；后者尚未访问核实。
- https://github.com/ztidal/codex-daodun-pet ：查看 `preview/contact-sheet.png`，刀盾狗为低趴圆滚滚柴犬形象，刀盾随身；不是之前图集中的肌肉棕狗。该项目声明原始参考图未收录，公开图为同人生成素材（CC BY 4.0），本工程不直接复制。
- https://github.com/KanadeK/miaocui-jiao-cat-codex-pet ：查看 README 与图集，灰白猫、大眼、小短腿。项目自述来自所有者确认的参考图，但并非网络首发来源证据。游戏仍保留用户指定的金色脆角耳与当身机制。
