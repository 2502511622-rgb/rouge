Switch 本地游戏启动器 · Windows 10/11 64 位
========================================

这是一款自制的本地启动器，不是 Switch 模拟器本身。
不附带模拟器、游戏、密钥或固件，也不会下载这些内容。

使用
----
1. 解压后双击 SwitchLauncher.exe。
2. 点击“选择模拟器”，选择你已安装并配置好的模拟器 EXE。
3. 选择与该模拟器版本兼容的参数模式：
   - 直接传路径：模拟器.exe "游戏路径"，例如支持此方式的 Ryujinx 类程序。
   - -g 参数：模拟器.exe -g "游戏路径"，例如支持此方式的 yuzu 类程序。
   名称只是参数约定示例，不代表已验证每个版本或衍生程序。
   如果不确定，请检查你本地模拟器的 --help 或官方说明。
4. 点击“添加游戏”可多选添加本地 .xci/.nsp/.nro/.nso 文件，也可把文件拖入窗口。
5. 选中游戏并点击“启动选中游戏”，或双击游戏名称。

模拟器本身必须能独立打开游戏。模拟器所需的硬件、驱动及配置仍由模拟器管理。
启动器不会自动安装更新/DLC，不会修改或解密游戏文件。
支持的扩展名只是文件选择范围，不表示对应内容能被任何模拟器加载。
游戏列表最多 256 项，重复路径自动忽略。列表选中后会显示完整路径。

配置与存档
----------
本启动器的配置保存在：
  %LOCALAPPDATA%\SwitchGameLauncher\config.ini

仅保存模拟器路径、参数模式和游戏列表。中文/空格路径使用 Unicode 保存和传递。
点击“打开配置目录”即可查看。升级启动器不会主动删除现有配置。
移除列表项只移除启动器记录，不删除游戏文件。
游戏存档、手柄设置、画面和声音由你选择的模拟器管理，不会移到本启动器目录。

范围与测试
----------
启动器直接调用 Windows CreateProcessW，不经过命令行 shell。
目前支持两种固定参数约定；需要其他参数的模拟器应先单独确认兼容方式。
公开 Windows CI 使用测试程序验证参数传递、工作目录、Unicode 配置和窗口启动。
没有使用商业游戏做自动测试，不承诺某款模拟器或游戏的实际兼容性。

源码与构建
----------
source/launcher.c 是启动器源码，build.py 是构建脚本。
Python 安装 ziglang==0.13.0 后执行：
  python source/build.py SwitchLauncher.exe
